# منصة تأسيس القدرات — ثانوية الأندلس بترقش

منصة يدخلها الطالب برقم هويته، فيرى بياناته ومسار المحاضرات (57 محاضرة / 60 مقطعًا من صفحة المدرسة).
يشاهد المحاضرة، ثم يختبر اختبارًا محاكيًا محوسبًا. إذا اجتاز تُفتح المحاضرة التالية، وإلا تُعرض عليه توصية بالمراجعة.
كل محاولة جديدة تسحب أسئلة لم تظهر له من قبل في نفس المحاضرة.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | صفحة الطالب |
| `admin.html` | لوحة المعلم: الطلاب، الأسئلة، المحاضرات، النتائج، الإعدادات |
| `schema.sql` | قاعدة البيانات كاملة مع المحاضرات الستين جاهزة |
| `config.js` | رابط ومفتاح مشروع Supabase |
| `قالب-الطلاب.xlsx` | مثال لشكل ملف الطلاب |

## تجربة سريعة قبل الربط
افتح `index.html` في المتصفح وادخل برقم الهوية `1111111111`. تعمل المنصة ببيانات تجريبية على جهازك فقط، وفيها أسئلة تجريبية للمحاضرتين 1 و2.

## التشغيل الفعلي (حوالي 15 دقيقة)
1. **أنشئ مشروعًا في Supabase**، ثم افتح SQL Editor والصق محتوى `schema.sql` كاملًا واضغط Run.
2. **أنشئ حساب المعلم:** من Authentication ← Users اختر Add user وأدخل بريدك وكلمة مرور.
   بعد ذلك شغّل في SQL Editor السطر التالي ببريدك:
   `insert into admins (email) values ('بريدك@example.com');`
3. **أوقف التسجيل العام:** من إعدادات Authentication عطّل خيار السماح بتسجيل مستخدمين جدد.
   هذه خطوة إضافية للحماية، لأن لوحة المعلم مقصورة أصلًا على البريد المسجل في جدول admins.
4. **اربط المنصة:** انسخ Project URL و anon public key من Project Settings ← API، وضعهما في `config.js`.
5. **انشر المجلد على Vercel:** ارفعه عبر GitHub أو بالسحب والإفلات، ولا يحتاج أي إعدادات بناء.
   يدخل الطلاب من الرابط الرئيسي، ويدخل المعلم من `/admin.html`.
6. **صلاحيات Google Drive:** تأكد أن كل مقاطع المحاضرات مشاركة بخيار «أي شخص لديه الرابط»، وإلا لن يظهر الفيديو داخل المنصة.

## بعد التشغيل
- **الطلاب:** من لوحة المعلم ← الطلاب، ارفع ملف Excel.
  تحدد أنت عمود الهوية وعمود الاسم، وكل بقية الأعمدة تظهر في بطاقة الطالب كما هي.
- **الأسئلة:** أضفها يدويًا، أو نزّل قالب الأسئلة واملأه وارفعه.
  يُفضَّل 20 سؤالًا أو أكثر لكل محاضرة إذا كان الاختبار 10 أسئلة، حتى تختلف الأسئلة بين المحاولات.
- **المحاضرات التي لا أسئلة لها بعد** لا توقف الطالب: ينتقل للتالية بعد أن يضغط «أنهيت المشاهدة».
- **الإعدادات:** نسبة الاجتياز (70% افتراضيًا) وعدد أسئلة الاختبار.

## ملفات PDF
- **كشف الطلاب:** من تبويب الطلاب ارفع PDF مثل كشوف نور، فيُقرأ رقم الهوية والاسم. إن ظهرت الأسماء مقلوبة فاستخدم خياري التصحيح في المعاينة. الكشوف الممسوحة ضوئيًا (صور) لا تُقرأ.
- **ملزمة المحاضرة:** من تبويب المحاضرات اضغط «إضافة PDF» بجانب المحاضرة.
- **ملفات الطلاب:** سمِّ كل ملف برقم هوية صاحبه (1234567890.pdf) وارفعها معًا من تبويب الطلاب.
- **الأسئلة:** كل سؤال يبدأ برقمه، ثم أ) ب) ج) د)، ثم «الإجابة: ب»، ثم «الشرح: ...» اختياريًا، وسطر «المحاضرة 3» قبل أسئلة كل محاضرة.
- روابط الملفات عشوائية ولا تظهر إلا لصاحبها داخل المنصة، لكن من يحصل على رابط ملف يستطيع فتحه.

## الاختبار المحاكي المتجدد
- المحاضرات المفعّل لها هذا النمط (حاليًا المحاضرة 1) يكون اختبارها 24 سؤالًا في 25 دقيقة بنمط قياس: مؤقت تنازلي، وتمييز الأسئلة، وصفحة مراجعة، وتسليم تلقائي عند انتهاء الوقت.
- الأسئلة تُولَّد من قوالب لكل مهارة شُرحت في المقطع، بأرقام وصيغ جديدة في كل محاولة، ولا يتكرر للطالب سؤال ظهر له سابقًا.
- بعد التسليم يرى الطالب درجته في كل مهارة، وشرح كل سؤال أخطأ فيه، والدقائق التي يراجعها في المقطع.
- القوالب في ملف exam-lecture-<رقم المحاضرة>.js، والتفعيل بالأمر: update lectures set exam_mode = 'generated' where id = <رقم>;

## الحماية
- لا يستطيع المتصفح قراءة الجداول مباشرة، ويعمل الطالب عبر دوال لا تعيد إلا بياناته هو.
- الإجابات الصحيحة لا تُرسل للمتصفح قبل التسليم، والتصحيح يتم في الخادم.
- قفل المحاضرات مُطبَّق في الخادم أيضًا، لا في الواجهة فقط.
- **ملاحظة:** الدخول برقم الهوية وحده يعني أن من يعرف رقم طالب يستطيع رؤية بطاقته. إن كانت بيانات الطلاب حساسة يمكن إضافة رمز ثانٍ لاحقًا، مثل آخر 4 أرقام من الجوال.
